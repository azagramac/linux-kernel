# 🐧 Linux Kernel 6.19.14

- **📅 Release date:** 22 April 2026
- **🌿 Series:** 6.19.y
- **📦 Type:** Stable maintenance release
- **⚠️ Status:** Final release — Linux 6.19.y is EOL

Linux **6.19.14** is the final maintenance release of the 6.19 kernel series. It contains a large set of upstream stable fixes covering security, memory management, filesystems, networking, virtualization, graphics, media, audio, storage, architecture-specific code and numerous device drivers.

> ⚠️ **Important:** Linux 6.19.14 is the **final 6.19.y release**. The 6.19 branch is no longer maintained upstream.

# 🔐 Security

Several changes address memory-safety problems, invalid bounds checks, race conditions and potential information disclosure.

### SMB/CIFS

* 🔒 Fixed an **off-by-8 bounds check** in `check_wsl_eas()`.
* 🔒 Prevented an untrusted SMB server from causing reads beyond the end of an extended-attribute buffer.
* 🔒 The previous implementation could potentially expose up to 8 bytes of kernel heap data during WSL extended-attribute processing.
* 🔒 Corrected additional SMB client parsing and bounds validation.

### KVM / virtualization

* 🔒 Fixed an important **KVM/SVM memory corruption issue** affecting AMD SEV-SNP.
* 🔒 Corrected handling of guest state during SEV-SNP launch.
* 🔒 Prevented invalid manipulation of VMSA pages.
* 🧪 Corrected KVM selftests for SEV-ES migration.
* 🛡️ Restricted KVM emulator scratch-buffer accesses to safe sizes and operations.
* 🛡️ Added sanity checks around emulator MMIO handling.

### Crypto

* 🔐 Corrected AEAD userspace crypto handling.
* 🔐 `algif_aead` was restored to **out-of-place operation**, avoiding the problematic in-place behaviour associated with the Copy-Fail vulnerability.
* 🔐 Various cryptographic API and implementation fixes were backported.

### Filesystem / kernel memory safety

* 🔒 Fixed multiple out-of-bounds accesses.
* 🔒 Fixed use-after-free conditions.
* 🔒 Corrected reference-counting and object lifetime issues.
* 🔒 Hardened parsing of filesystem and protocol structures.
* 🔒 Fixed several integer/bounds calculations.

# 🧩 Notable low-level fixes

### `dma-mapping`

```text
DMA_ATTR_CPU_CACHE_CLEAN
```

is now correctly represented by tracing infrastructure.

### `dma-debug`

Repeated overlapping mappings no longer incorrectly trigger the seven-mapping diagnostic limit.

### `dcache`

The minimum dentry hash-table size is now constrained to prevent invalid shift calculations.

### x86 user-copy

The misleading:

```text
__copy_user_nocache()
```

implementation was renamed and its API semantics clarified.

### KVM

Emulator scratch storage is now constrained to safe access patterns.

### SMB

Bounds checks now use the actual location of:

```text
ea->ea_data
```

rather than assuming a fixed structure offset.
