# 🐧 Linux Kernel 7.3.6

- **📅 Release date:** 23 November 2026
- **🌿 Series:** 7.3 stable
- **📦 Type:** Stable maintenance release
- **✅ Status:** Released

Linux **7.3.6** is a stable maintenance release focused on kernel correctness, memory safety, networking reliability, synchronization, hardware drivers and architecture-specific fixes.

This release incorporates a substantial collection of upstream stable patches addressing issues across multiple kernel subsystems. Notable changes include Bluetooth L2CAP synchronization fixes, TCP socket lifetime corrections, Hugetlb and Userfaultfd improvements, RDMA memory-bound validation, BPF/libbpf corrections, DMA resource management and numerous hardware driver fixes.

> 📌 **Linux 7.3.6 strengthens system reliability by correcting race conditions, memory corruption risks, resource leaks, invalid memory accesses and hardware driver handling across the kernel.**

---

## 📋 Release overview

- **🧠 Memory management:** Improves Hugetlb page-table handling, Userfaultfd isolation, vmalloc reading and memory access validation.
- **🌐 Networking:** Fixes TCP socket lifetime issues, IPv6 route synchronization, PPP packet handling and networking resource management.
- **📡 Bluetooth:** Corrects L2CAP locking, connection shutdown races and Bluetooth 6LoWPAN peer management.
- **💽 Filesystems:** Improves OCFS2 extended attribute validation and filesystem metadata consistency.
- **🔗 RDMA / InfiniBand:** Fixes out-of-bounds access in RXE memory registration and improves memory access validation.
- **🧩 BPF / eBPF:** Corrects libbpf program flag handling and improves XDP program compatibility.
- **⚙️ DMA / I/O:** Fixes DMA descriptor management, resource cleanup and synchronization.
- **🔊 Audio:** Improves ASoC driver initialization, runtime power management and hardware-specific microphone handling.
- **🎮 Graphics / DRM:** Includes AMD display pipeline corrections and hardware-specific display handling.
- **🏗️ Architecture support:** Includes x86, ARM64, MIPS, RISC-V, PowerPC and other architecture-specific fixes.
- **🛡️ Security:** Addresses use-after-free, out-of-bounds memory access, invalid metadata handling and concurrent access vulnerabilities.
- **🛠️ Hardware drivers:** Includes corrections for SPI, DMA, audio, PCI, networking and other hardware subsystems.

# 🧠 Memory Management

## 💾 Hugetlb / Userfaultfd

### Improve huge-page isolation and page-table handling

- 🔧 Disables PMD sharing for Userfaultfd missing mode registrations.
- 🛡️ Prevents poisoned-page markers installed through `UFFDIO_POISON` from becoming visible to other processes sharing the same PMD table.
- 🧠 Improves isolation between processes using shared Hugetlb page tables.
- ⚙️ Adds additional validation around poisoned-page marker installation.
- 🔒 Prevents incorrect page-table sharing in Userfaultfd-managed mappings.

## 🧠 Virtual Memory / MM

### Improve memory access and validation

- 🔧 Corrects memory access handling in `vread_iter()`.
- 🛡️ Fixes incorrect source pointer advancement when partial reads occur across multiple iovecs.
- 🔧 Prevents incorrect memory copying and unsigned length underflow during partial reads.
- ⚙️ Improves memory mapping and page-table consistency.
- 🧵 Includes additional memory management and synchronization corrections.

# 🌐 Networking

## 🔗 TCP / IPv4

### Improve TCP socket lifecycle and synchronization

- 🛡️ Fixes a potential double destruction of TCP child sockets in `tcp_abort()`.
- 🔒 Prevents double `sock_put()` operations and potential use-after-free conditions.
- 🔧 Revalidates TCP socket state after acquiring the bottom-half lock.
- 🧵 Improves synchronization between socket abortion and listener shutdown.
- ⚙️ Corrects socket lifetime handling during concurrent operations.

## 🌍 IPv6

### Improve route table synchronization

- 🔒 Protects concurrent IPv6 multipath route insertion using the routing table lock.
- 🛡️ Prevents concurrent modifications of `fib6_siblings`.
- 🔧 Corrects synchronization in IPv6 route insertion and deletion.
- ⚙️ Improves routing table consistency and prevents invalid memory access.

## 📡 PPP / PPPoE

### Fix packet processing and segmentation

- 🔧 Corrects handling of non-linear PPP packets.
- 🛡️ Prevents unintended packet data leakage.
- ⚙️ Fixes GSO segmentation for IPv4 and IPv6.
- 🔧 Improves checksum handling for `CHECKSUM_PARTIAL` packets.
- 🚀 Corrects packet handling across PPPoE, PPP Async and bridged interfaces.

## 🌐 Additional networking fixes

- 🔧 Improves RDS initialization and error handling.
- 🛡️ Fixes workqueue lifetime management in RDS and RDS/RDMA.
- 🔒 Improves socket reference handling and concurrent destruction.
- ⚙️ Includes additional routing, network device and protocol corrections.

# 📡 Bluetooth

## 🔵 Bluetooth / L2CAP

### Fix connection synchronization and locking

- 🔒 Corrects locking in `__l2cap_ecred_conn_rsp_defer()`.
- 🧵 Ensures `conn->lock` is held when accessing shared channel lists.
- 🔧 Fixes a race condition in `l2cap_sock_shutdown()`.
- 🛡️ Prevents concurrent connection operations from accessing channel lists without the required synchronization.
- ⚙️ Uses `l2cap_chan_close_unlocked()` to ensure the required connection locking.
- 🔧 Improves lock ordering between connections, channels and sockets.

## 📶 Bluetooth 6LoWPAN

### Improve peer lifecycle management

- 🛡️ Prevents concurrent `peer_del()` operations from freeing peer structures while they are being accessed.
- 🔒 Adds the necessary `devices_lock` protection.
- 🔧 Corrects L2CAP channel closure and connection management.
- ⚙️ Improves synchronization during Bluetooth 6LoWPAN disconnection.

# 💽 Filesystems / Storage

## 📁 OCFS2

### Improve extended attribute validation

- 🛡️ Prevents kernel BUG conditions caused by corrupted local extended attribute entries.
- 🔧 Validates the relationship between `OCFS2_XATTR_ENTRY_LOCAL` and `xe_value_size`.
- ⚙️ Improves validation in flat and bucket-based extended attribute metadata.
- 🔒 Rejects inconsistent metadata before accessing inline attribute values.
- 🛡️ Returns filesystem corruption errors instead of triggering kernel assertions.
- 🔧 Improves reliability when removing or modifying extended attributes.

## 💾 Additional storage fixes

- 🔧 Includes corrections to block-device and I/O resource management.
- 🛡️ Improves memory lifetime handling and error recovery.
- ⚙️ Fixes resource cleanup in hardware storage interfaces.

# 🔗 RDMA / InfiniBand

## 🧠 RXE / On-Demand Paging

### Fix memory bounds validation

- 🛡️ Fixes an out-of-bounds read in the RXE RDMA implementation.
- 🔧 Validates memory region indices against the registered user-memory range.
- 🔒 Prevents unprivileged local users from accessing memory outside registered RDMA regions.
- ⚙️ Ensures invalid memory accesses are rejected through the appropriate fault-handling path.
- 🧠 Improves memory safety in RDMA operations involving On-Demand Paging (ODP).

# 🧩 BPF / eBPF

## 🔧 libbpf

### Improve program flag handling

- 🔧 Moves section-defined program flags into `prog_flags`.
- 🛡️ Makes XDP fragment and sleepable program flags accessible through the public libbpf API.
- ⚙️ Improves compatibility with applications using `bpf_program__flags()`.
- 🔧 Preserves program flags across program type changes.

## 🚀 bpftool / XDP

- 🔧 Corrects non-destructive handling of `BPF_F_XDP_DEV_BOUND_ONLY`.
- 🛡️ Prevents existing BPF program flags from being overwritten.
- ⚙️ Improves compatibility with XDP fragment-enabled programs.
- 🧵 Includes additional BPF JIT and architecture-specific corrections.

# ⚙️ DMA / Hardware I/O

## 🔄 DMA Engine

### Improve descriptor and resource management

- 🔧 Fixes descriptor cleanup in the Freescale RAID DMA engine.
- 🛡️ Prevents descriptor-list corruption when allocated descriptors differ from the available free descriptors.
- 🔒 Moves DMA completion callbacks outside the descriptor spinlock to prevent recursive locking and deadlocks.
- ⚙️ Improves DMA resource cleanup and descriptor lifecycle management.
- 🔧 Corrects memory address typing in the Atmel DMA driver.
- 🛡️ Fixes device-tree reference leaks in the ST-Ericsson DMA40 driver.
- ⚙️ Corrects SRAM resource cleanup and error handling.

## 🔌 SPI

- 🔧 Fixes a clock resource leak in the MXIC SPI controller.
- 🛡️ Ensures `ps_clk` is disabled if subsequent clock initialization fails.
- ⚙️ Improves runtime power-management error handling.

**📌 Final assessment**

Linux **7.3.6** is primarily a reliability and correctness release. Its most relevant improvements concern memory safety, concurrent access, networking synchronization, Bluetooth connectivity, RDMA validation and hardware resource management.

The update does not introduce a major new kernel subsystem or a specific performance-oriented feature. Its value lies in correcting existing implementation problems and reducing the risk of kernel crashes, memory corruption, deadlocks and resource leaks.

**Recommendation:** Upgrade installations running Linux 7.3.x to 7.3.6 to incorporate the latest stable maintenance fixes.
