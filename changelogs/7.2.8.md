# 🐧 Linux Kernel 7.2.8

* **📅 Release date:** 25 September 2026
* **🌿 Series:** 7.2.y
* **📦 Type:** Stable maintenance release
* **✅ Status:** Current stable 7.2.y release

Linux **7.2.8** is a stable maintenance release in the Linux 7.2 kernel series. It contains a large set of upstream stable fixes covering security, memory management, graphics, filesystems, networking, wireless, storage, virtualization, RDMA, audio, architecture-specific code and numerous device drivers.

The release contains **439 changed files**, with **6,817 insertions and 2,709 deletions**. Upstream recommends that users of the Linux 7.2 series upgrade to this release.

> 📌 **Linux 7.2.8 is a maintenance release focused on correctness, stability, memory safety, hardware compatibility and resource-lifetime fixes.**

# 🔐 Security & Memory Safety

Linux 7.2.8 contains a significant number of security-oriented correctness fixes. Several address **out-of-bounds accesses, use-after-free conditions, integer overflows, invalid reference lifetimes and insufficient input validation**.

### XFRM / IPsec

* 🔒 Fixed a **stack out-of-bounds read** in `xfrm_iptfs`.
* 🔒 Fixed a panic during IP-TFS reassembly when the inner packet has an invalid/short `tot_len`.
* 🔒 Fixed a **use-after-free** in the compat `ALLOCSPI` request path.
* 🔒 Added the missing RCU read-side protection in `xfrm_send_migrate_state()`.
* 🔒 Added required device/network references when reinjecting XFRM traffic.
* 🔒 Corrected XFRM state-cache removal using RCU-safe list operations.
* 🛡️ Rejected ESP-in-TCP transport headers that cannot be represented safely.
* 🧹 Corrected several XFRM state and reference-lifetime paths.

### Bluetooth

* 🔒 Validated Bluetooth service-data lengths before reading UUID information.
* 🔒 Added TX-SKB length validation to the Intel PCIe Bluetooth driver.
* 🔒 Added vendor-codec count validation.
* 🔒 Corrected several Bluetooth ISO socket and workqueue lifetime issues.
* 🧹 Prevented work from being queued after the Bluetooth workqueue has been drained.

### Input subsystem

* 🔒 Fixed partial userspace-copy handling in `evdev`.
* 🔒 Zeroed structures before partially copying userspace data.
* 🔒 Clamped HID report sizes before performing `memcpy()`.
* 🛡️ Added additional validation to touchscreen, keyboard and gamepad drivers.

### Kernel Keys / TPM

* 🔐 Fixed an integer overflow involving `datablob_len` in encrypted keys.
* 🔒 Added boundary checking to `tpm2_load_cmd()`.
* 🛡️ Corrected key-management reference and wakeup handling.
* 🔐 Improved handling of `request_key_auth` PID translation.

### RDMA

* 🔒 Fixed an integer overflow in `RDMA/rxe` that could lead to an out-of-bounds access.
* 🛡️ Corrected RDMA object lifetime handling.
* 🔒 Prevented invalid memory registration operations.
* 🧹 Fixed multiple reference-count and resource-release paths.

# 🖥️ Graphics / DRM

## 🎮 AMDGPU

Linux 7.2.8 contains several important AMDGPU fixes.

### PCIe capability reporting

* 🔧 Fixed **GPU PCIe link capability reporting**.
* 🧩 Correctly distinguishes the GPU PCIe capabilities from those of the host PCIe port.
* 🖥️ Prevents incorrect PCIe generation and link-width information from being exposed.

### SR-IOV initialization

* 🚀 Reduced early full-GPU access during AMDGPU SR-IOV initialization.
* 🧩 Restricted the BAR0 fallback read to **SR-IOV Virtual Functions**.
* 🔧 Improves GPU initialization when the VRAM aperture is not yet available.

### Runtime power management

* ⚡ Added a runtime-PM reference for P2P DMA-BUF attachments.
* 💤 Prevents buffer migration failures when an exporting GPU is runtime suspended.
* 🔧 Allows the driver to keep buffers in GTT when the GPU cannot safely access VRAM while powered down.

### RAS

* 🛡️ Added NULL checks for AMDGPU RAS objects before dereferencing them.
* 🔧 Prevents a possible crash in the NBIO v7.9 RAS interrupt handler during the initialization window.

### KFD

* 🧠 Avoided clearing KFD mappings before the required initialization has completed.
* 🔧 Added MQD restore callbacks for GFX12 and GFX12.1.

### Other AMDGPU fixes

* 🧹 Fixed `rmmio` unmapping during device removal.
* 🔧 Corrected GPU resource cleanup.
* 🛠️ Fixed several AMDGPU device-management corner cases.

> **Summary:** Linux 7.2.8 is a broad **stable maintenance release** with a strong emphasis on memory safety, resource lifetime, GPU/DRM correctness, filesystem robustness, networking security and hardware-driver stability. It is especially notable for AMDGPU/TTM, SMB/CIFS, XFRM, Wi-Fi, RDMA, DMA and memory-management fixes.
