
# 🐧 Linux Kernel 7.3.5

- **📅 Release date:** 17 November 2026
- **🌿 Series:** 7.3 stable
- **📦 Type:** Stable maintenance release
- **✅ Status:** Released

Linux **7.3.5** is a stable maintenance release focused on kernel correctness, memory safety, filesystem reliability, networking and hardware driver fixes.

This release incorporates a broad collection of upstream stable patches addressing issues across multiple kernel subsystems. Notable changes include AMD IOMMU and x86 memory-management fixes, Hugetlb and swap handling improvements, AMDGPU scheduling corrections, filesystem fixes, networking synchronization and cryptographic API hardening.

> 📌 **Linux 7.3.5 improves system reliability through fixes to memory management, synchronization, resource handling, GPU drivers, networking and asynchronous I/O.**

---

## 📋 Release overview

- **🧠 Memory management:** Fixes Hugetlb `mremap()` handling, swapoff interruptibility, shmem and tmpfs quota management, and memory reclaim issues.
- **🎮 AMDGPU / DRM:** Improves GPU queue synchronization, scheduler handling, fence management and hardware reset coordination.
- **💽 Filesystems:** Fixes issues in F2FS, OverlayFS, tmpfs, CIFS/SMB and other filesystem components.
- **🌐 Networking:** Improves batman-adv mesh networking, CAN/SocketCAN, L2TP and socket synchronization.
- **🔐 Cryptography:** Hardens ML-DSA signature verification and corrects Octeon SHA implementations on little-endian systems.
- **⚙️ I/O:** Fixes `io_uring` polling, cancellation, SQPOLL thread lifecycle and asynchronous operation handling.
- **🛠️ Hardware drivers:** Includes fixes for AMD audio, hwmon, PMBus, Aquacomputer devices and other hardware drivers.
- **🏗️ Architecture support:** Includes x86, MIPS, AMD IOMMU and platform-specific corrections.
- **🛡️ Security:** Addresses memory safety issues, incorrect reference handling and an AMD IOMMU mitigation for CVE-2024-21963.

# 🧠 Memory Management

## 💾 Hugetlb

### Fix memory mapping and page-table handling

- 🔧 Corrects integer truncation in `move_hugetlb_page_tables()` when moving large memory regions through `mremap()`.
- 🧠 Changes the return type to `unsigned long` to preserve the full number of bytes moved.
- 🛡️ Disables PMD sharing in Userfaultfd missing mode to prevent poisoned-page markers from becoming visible through shared page tables.
- 🔒 Fixes a recursive `i_mmap_rwsem` deadlock in the Hugetlb `mremap()` path.

## 🧠 Virtual Memory / MM

### Improve swapoff interruptibility

- 🔧 Makes `swapoff` interruptible while restoring swapped-out memory mappings.
- 🧵 Adds signal checks during anonymous memory and shmem restoration.
- 🛡️ Prevents long-running swap operations from blocking system suspend and hibernation.
- ⚡ Improves freezer responsiveness when large amounts of swapped memory are being restored.

### Fix shmem and tmpfs quota handling

- 💾 Preserves explicitly disabled user and group quota limits.
- 🔧 Prevents quota soft limits from being discarded when unused quota records are released.
- 🛡️ Corrects quota record persistence and prevents unexpected enforcement of mount defaults.
- 🧵 Improves consistency of tmpfs quota management.

### Improve memory management correctness

- 🔧 Fixes a false-positive GCC `-Wuninitialized` warning in memory reclaim code.
- 🛡️ Fixes shmem truncation handling when large folios cannot be split.
- 🔧 Corrects tagged address handling in `move_pages()` queries.
- ⚙️ Improves memory policy accounting for shared NUMA policy nodes.
- 🧵 Includes additional fixes to memory migration, reclaim and page management.

# 🎮 Graphics / DRM / AMDGPU

## 🔴 AMDGPU

### Fix GPU scheduler and fence management

- 🛡️ Fixes dependency fence reference handling in AMDGPU job scheduling.
- 🔧 Corrects reference ownership when `drm_sched_job_add_dependency()` fails.
- 🧵 Prevents incorrect release of DMA fence references.
- ⚙️ Improves GPU scheduler resource management.

### Improve GPU queue synchronization

- 🔧 Synchronizes AMDGPU user queue operations with GPU reset handling.
- 🛡️ Prevents MES operations from accessing hardware while a GPU reset is in progress.
- ⚙️ Improves queue mapping, unmapping and eviction handling.
- 🔧 Corrects KFD queue creation and memory mapping error handling.

### Improve GPU error handling

- 🛡️ Corrects AMDGPU MES ring timeout reporting.
- 🔧 Improves error propagation during GPU command submission.
- ⚙️ Includes additional fixes to GPU memory management and device synchronization.

## 🖥️ DRM / Display

- 🔧 Includes fixes to DRM bridge and display synchronization handling.
- 🛡️ Improves resource management and synchronization in display driver paths.
- ⚙️ Includes additional hardware-specific DRM corrections.

# 🌐 Networking

## 🔗 L2TP

### Fix L2TPv3 session handling

- 🔧 Corrects L2TPv3 session lookup and tunnel identification.
- 🛡️ Improves session isolation when multiple tunnels are configured.
- ⚙️ Fixes session management and error handling.

## 📡 batman-adv

### Improve mesh networking reliability

- 🔧 Fixes client roaming state handling in translation tables.
- 🛡️ Corrects inconsistencies between local and global translation table entries.
- 🧵 Fixes potential memory leaks during interface and originator cleanup.
- 🔧 Corrects uninitialized candidate entries in Distributed ARP Table (DAT) selection.
- ⚙️ Fixes socket buffer leaks during hardware interface release.
- 🛡️ Corrects multicast tracker padding validation to prevent packet memory corruption.
- 🔧 Fixes throughput meter reporting when transferred data exceeds 4 GB.

## 🚗 CAN / SocketCAN

### Improve CAN networking synchronization

- 🔒 Improves synchronization of CAN receive lists.
- 🧵 Corrects locking and socket handling during network namespace operations.
- 🔧 Improves socket option handling and locking behavior.
- 🛡️ Prevents invalid CAN XL frames from reaching devices without CAN XL support.
- ⚙️ Improves CAN packet validation and error handling.

### Fix CAN frame handling

- 🔧 Corrects CAN XL frame validation.
- 🛡️ Prevents CAN XL frames from being incorrectly interpreted by devices that only support CAN or CAN FD.
- ⚙️ Improves memory safety in CAN transmission and reception paths.

## 🌍 Additional networking fixes

- 🔧 Improves socket synchronization and reference handling.
- 🛡️ Fixes resource leaks in networking interfaces.
- ⚙️ Includes additional corrections to virtual Ethernet devices and network device state handling.

# 💽 Filesystems / Storage

## 📁 OverlayFS

### Improve file handle handling

- 🔧 Corrects OverlayFS index lookup using decoded lower filesystem origins.
- 🛡️ Improves lower-layer file handle resolution.
- 🔒 Fixes incorrect file handle handling and associated `ESTALE` errors.
- ⚙️ Improves NFS export compatibility.

### Improve user namespace handling

- 🔧 Corrects error handling when completing OverlayFS filesystem contexts across mismatched user namespaces.
- 🛡️ Improves validation of namespace combinations.

## 💾 F2FS

### Improve write completion handling

- 🔧 Replaces `in_atomic()` with `bio_in_atomic()` in `f2fs_write_end_io()`.
- 🛡️ Correctly detects atomic execution contexts involving disabled interrupts and RCU read-side critical sections.
- ⚙️ Ensures oversized write BIO completion is deferred to the appropriate workqueue when necessary.

## 🗂️ tmpfs / shmem

- 🔧 Improves quota persistence across record release and reacquisition.
- 🛡️ Preserves explicitly disabled quota limits.
- ⚙️ Corrects handling of default and user-defined quota values.
- 🔧 Fixes shmem truncation behavior when large folios cannot be split.
- 🧵 Improves synchronization during concurrent truncation and memory operations.

## 🖥️ CIFS / SMB / ksmbd

- 🔒 Fixes credential cleanup when ksmbd work initialization fails.
- 🛡️ Prevents incorrect credentials from being retained and reused by subsequent worker operations.
- 🔧 Prevents creation of AFP metadata streams on read-only SMB shares.
- ⚙️ Improves SMB filesystem error handling.

# 🔐 Cryptography

## 🛡️ Linux Crypto API

### Improve ML-DSA verification safety

- 🔒 Adds `__must_check` to `mldsa_verify()`.
- 🛡️ Ensures callers explicitly check signature verification results.
- 🔧 Validates the algorithm parameter passed to `mldsa_verify()`.
- 🛡️ Checks public key length before performing pointer arithmetic.
- ⚙️ Improves API robustness and consistency with existing AES-GCM and ChaCha20-Poly1305 implementations.

### Fix Octeon SHA implementations

- 🔧 Disables incorrect Octeon SHA-1, SHA-256 and SHA-512 implementations on little-endian kernels.
- 🛡️ Ensures generic implementations are used where the optimized implementations produce incorrect results.
- ⚙️ Preserves optimized Octeon SHA support on big-endian systems.

# ⚙️ I/O / Block Layer

## 🚀 io_uring

### Improve asynchronous I/O handling

- 🔧 Fixes polling behavior and error handling for asynchronous file operations.
- 🛡️ Corrects handling of `POLLERR`, `POLLNVAL` and `POLLHUP` conditions.
- 🔧 Fixes asynchronous cancellation handling, including `IORING_ASYNC_CANCEL_ALL`.
- ⚡ Improves cancellation efficiency when multiple polling requests are pending.
- ⚙️ Improves futex wait/wake and `WAITID` operation handling.
- 🧵 Improves consistency of asynchronous operation completion and cancellation.

### Fix SQPOLL thread lifecycle

- 🔧 Corrects SQPOLL thread shutdown and cancellation handling.
- 🛡️ Prevents new rings from attaching to threads that are already exiting.
- ⚙️ Fixes thread state handling when fatal signals terminate SQPOLL threads.
- 🧵 Ensures return-to-userspace work is executed correctly by SQPOLL threads.

## 💽 Storage and memory I/O

- 🔧 Improves BIO execution-context detection.
- 🛡️ Corrects completion handling for operations executed in atomic contexts.
- ⚙️ Includes additional block and filesystem I/O correctness fixes.

# 🏗️ Architecture / Platform Support

## 🔴 AMD / x86

- 🛡️ Forces the AMD IOMMU device table to its maximum supported size on affected processors.
- 🔒 Includes a mitigation for **CVE-2024-21963**.
- 🔧 Fixes global ASID allocation to prevent two processes from receiving the same global ASID.
- 🛡️ Prevents incorrect TLB entry sharing between processes.
- ⚙️ Improves AMD IOMMU device-table reuse during kdump.
- 🧵 Corrects architecture-specific memory management and synchronization.

## 🏗️ Other architectures

- 🔧 Includes MIPS platform compatibility fixes.
- 🛡️ Corrects architecture-specific cryptographic implementations.
- ⚙️ Includes additional ARM64 and platform-specific corrections.

# 🔒 Security / Reliability

- 🛡️ Fixes potential out-of-bounds memory access in AMD IOMMU device-table handling.
- 🔒 Includes mitigation for **CVE-2024-21963**.
- 🛡️ Fixes a global ASID allocation issue that could allow processes to access or corrupt each other's memory through shared TLB entries.
