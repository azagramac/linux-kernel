# 🐧 Linux Kernel 7.3.3

- **📅 Release date:** 6 November 2026
- **🌿 Series:** 7.3 stable
- **📦 Type:** Stable maintenance release
- **✅ Status:** Released

Linux **7.3.3** is a stable maintenance release focused on security and correctness fixes in the Xen backend drivers.

This release includes three fixes addressing potential use-after-free (UAF) conditions in Xen block and network backend drivers. The issues involve concurrent access to I/O statistics and network statistics during device teardown.

> 📌 **Linux 7.3.3 primarily addresses three Xen security vulnerabilities, improving memory lifetime management and synchronization during backend device disconnection and cleanup.**

---

## 📋 Release overview

- **🛡️ Xen block backend:** Fixes a potential use-after-free when reading I/O statistics during frontend device teardown.
- **🌐 Xen network backend:** Fixes unsafe multicast address list cleanup during network backend disconnection.
- **🛡️ Xen network backend:** Fixes a potential use-after-free when reading network statistics during queue teardown.
- **🔒 Security:** Addresses three vulnerabilities: CVE-2026-100080, CVE-2026-100081 and CVE-2026-100082.
- **🧵 Synchronization:** Improves locking and RCU synchronization to prevent access to freed memory.

---

# 🛡️ Security / Xen

## 💽 Xen block backend (`xen-blkback`)

### Fix use-after-free when reading I/O statistics

- 🛡️ Fixes a potential use-after-free when reading I/O statistics through sysfs while a frontend device is being disconnected.
- 🧵 Introduces a read-write lock to synchronize access to statistics data with device teardown.
- 🔧 Prevents concurrent access to memory being freed during frontend disconnection.
- 🔒 Addresses **XSA-528 / CVE-2026-100082**.

## 🌐 Xen network backend (`xen-netback`)

### Defer multicast address list cleanup

- 🛠️ Moves `xenvif_mcast_addr_list_free()` out of `xenvif_disconnect_data()`.
- 🧵 Defers multicast address list cleanup until TX/RX processing has stopped.
- 🔒 Ensures cleanup occurs after the synchronization point in `backend_disconnect()`.
- 🛡️ Prevents race conditions between multicast address lookups and modifications during network backend teardown.
- 🔒 Addresses **XSA-527 / CVE-2026-100081**.

### Fix use-after-free when reading network statistics

- 🛡️ Fixes a potential use-after-free when reading network statistics through sysfs during queue teardown.
- 🧵 Adds `synchronize_net()` before freeing queue data protected by RCU.
- 🔧 Ensures outstanding network readers have completed before releasing associated memory.
- 🔒 Prevents access to freed or subsequently reused memory.
- 🔒 Addresses **XSA-526 / CVE-2026-100080**.
